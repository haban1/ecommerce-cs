# 通用客服 Skill

## 功能描述
处理通用客服问题和常见咨询，包括：
- 账号问题（注册、登录、密码）
- 支付问题（支付方式、发票）
- 配送问题（配送范围、时效）
- 平台服务（客服联系、营业时间）
- 其他常见问题

## 工作流程

### 1. 识别问题分类
判断问题属于哪个类别：
- **account**: 账号相关
- **payment**: 支付相关
- **delivery**: 配送相关
- **after_sales**: 售后服务联系方式

### 2. 检索 FAQ
调用知识检索：
```
search_knowledge(
  query="用户问题",
  knowledge_type="faq",
  filter_field="category",
  filter_value="问题分类",
  top_k=5
)
```

### 3. 匹配最佳答案
从检索结果中选择最相关的 FAQ，提取官方回答。

### 4. 格式化回复
直接给出答案，简洁明了。如果 FAQ 中没有答案，建议联系人工客服。

## 示例对话

**场景1：账号问题**

**用户**: 怎么修改密码  
**助手**: [调用 search_knowledge] 修改密码步骤：
1. 登录账号
2. 进入"账号设置"
3. 点击"修改密码"
4. 输入旧密码和新密码
5. 点击"确认"保存

**场景2：支付问题**

**用户**: 支持哪些支付方式  
**助手**: [调用 search_knowledge] 我们支持以下支付方式：
- 微信支付
- 支付宝
- 银行卡支付
- 花呗分期

**用户**: 可以开发票吗  
**助手**: [调用 search_knowledge] 可以开具电子发票：
1. 订单完成后，进入"我的订单"
2. 点击"申请发票"
3. 填写发票信息（抬头、税号）
4. 提交后1-3个工作日发送到邮箱

**场景3：配送问题**

**用户**: 配送要多久  
**助手**: [调用 search_knowledge] 配送时效：
- **同城**: 1-2天
- **省内**: 2-3天
- **跨省**: 3-5天
- **偏远地区**: 5-7天

**场景4：联系客服**

**用户**: 怎么联系人工客服  
**助手**: 您可以通过以下方式联系人工客服：
- **电话**: 400-XXX-XXXX（工作日 9:00-18:00）
- **在线客服**: 点击右下角"在线咨询"
- **邮箱**: service@example.com

## 注意事项
- FAQ 答案通常比较标准化，直接引用即可
- 如果 FAQ 中没有答案，建议用户联系客服
- 涉及账号安全的问题，提醒用户注意保护隐私
- 作为兜底 Skill，优先级最低
